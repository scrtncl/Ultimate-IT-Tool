Access level

scrtncl only does what the current level allows. Higher levels need your router login.

Level 1: No login

Works on almost any router.

  • Router reachable
  • Speed to the router
  • DNS and internet checks

Level 2: Read only Current

Reads data after you log in. Changes nothing.

  • Uptime and WAN status
  • Interface counters
  • Connected clients and logs

Level 3: Changes

Needs a backup and your approval each time.

  • Back up the configuration
  • Change supported settings
  • Restart selected services

Router login

Needed for Level 2 and Level 3. scrtncl never tries default passwords.

Make a change

Level 3 only. You see the plan first, and nothing runs until you approve it.

Sample plan: Change DNS servers

  • Back up the current configuration first
  • Change the DNS servers on the WAN interface
  • Warning: devices may lose internet for about 10 seconds
  • Run the Network Doctor again to check the result
  • Roll back from the backup if the check fails

How risky is each change?

Riskier changes need more approval.

Risk Example What scrtncl requires
Read only Ping, view status, read logs Nothing extra
Low Clear the local DNS cache Your confirmation
Medium Change DNS, renew a lease, restart an adapter Your approval and a warning about losing connection
High Change router firewall, WAN, or Wi-Fi settings Admin approval, a backup, and a rollback plan
Critical Factory reset, firmware flashing A separate manual process. Never automatic.
Use this tool only on networks and routers you own or have permission to manage.
